# harness_your_hopes

Learning agent-harness engineering by building against local models. Start here:

1. [`learning-agent-harnesses-locally.md`](./learning-agent-harnesses-locally.md) — the why and the full project ladder
2. [`PLAN.md`](./PLAN.md) — progress tracker, update as you complete each project's Build/Done-when/Measure steps
3. [`projects/`](./projects/) — one folder per rung of the ladder, each with a `README.md` (actionable checklist) and stub code to fill in
4. [`common/`](./common/) — shared Ollama client used by every project

Setup (once): see the "Local setup (Windows)" section of the main doc, then the Environment checklist in `PLAN.md`.
